## ขั้นที่ 1 — ติดตั้ง rich menu (คำสั่งเดียว)

```powershell
cd F:\GitHub\it-support-admin\line-oa
python setup_richmenu.py
```

สคริปต์จะอ่าน `LINE_CHANNEL_ACCESS_TOKEN` จาก `line-bot-python\.env` ให้เอง แล้วทำ 3 อย่างตามลำดับ:
สร้างเมนู → อัปโหลดรูป → ตั้งเป็นเมนูเริ่มต้นของผู้ใช้ทุกคน

รันซ้ำได้ตลอด — ก่อนสร้างใหม่มันจะลบเมนูเก่าที่ชื่อ `IT Support Main Menu` ทิ้งให้ก่อน จึงไม่มีเมนูค้างสะสม
(เมนูค้างคือปัญหาที่เจอบ่อยเวลาตั้งด้วยมือ เพราะ LINE ยอมให้ 1 แชนแนลมีได้ถึง 1,000 เมนู แต่แสดงได้ทีละอัน)

```powershell
python setup_richmenu.py --list     # ดูเมนูที่มีอยู่จริงในแชนแนล
python setup_richmenu.py --remove   # ถอดเมนูออกทั้งหมด (ย้อนกลับ)
```

> **หลังติดตั้งแล้วยังไม่เห็นเมนู?** ปิดห้องแชทแล้วเปิดใหม่ 1 ครั้ง — แอป LINE แคชเมนูไว้ฝั่งเครื่อง
> ไม่ได้แปลว่าตั้งค่าพลาด

## ปุ่มแต่ละปุ่มยิงอะไร

| ตำแหน่ง | ปุ่ม | ส่งอะไรไปหาบอท | บอทตอบด้วยอะไร |
| --- | --- | --- | --- |
| บน-ซ้าย | แจ้งซ่อม | ข้อความ `แจ้งซ่อม` | เปิด flow แจ้งเรื่อง intent=`repair` |
| บน-กลาง | เบิกอุปกรณ์ | ข้อความ `เบิกอุปกรณ์` | intent=`withdraw` |
| บน-ขวา | คืนอุปกรณ์ | ข้อความ `คืนอุปกรณ์` | intent=`return` |
| ล่าง-ซ้าย | ขอใช้บริการ IT | ข้อความ `ขอใช้บริการ IT` | intent=`it_service` |
| ล่าง-กลาง | เรื่องที่ฉันแจ้ง | ข้อความ `เรื่องที่ฉันแจ้ง` | `my_tickets_query` → ดึง ticket ของคนนั้นมาตอบ |
| ล่าง-ขวา | คำถามที่พบบ่อย | postback `a=faq_menu` | `flow.py` เปิดเมนู FAQ |

ห้าปุ่มแรกใช้ action แบบ `message` โดยตั้งใจ ไม่ใช่ `postback` — เพราะบอทมีชั้นจับ intent อยู่แล้ว
(`ai.py` → `INTENT_KEYWORDS`) การส่งข้อความธรรมดาจึงเข้า flow ได้เลยโดยไม่ต้องเพิ่ม action ใหม่ใน `flow.py`
ได้ผลพลอยได้คือผู้ใช้เห็นคำที่ตัวเองส่งในแชท เลยเรียนรู้ว่า "พิมพ์เองก็ได้" ไม่ติดกับการกดปุ่มอย่างเดียว

ตรวจแล้วด้วยการเรียก `ai.analyze()` จริงกับข้อความทั้ง 5 — เข้า intent ถูกทุกตัว
(`repair` 0.60, `withdraw` 0.60, `return` 0.60, `it_service` 0.85, `my_tickets_query` 0.85)

ส่วน FAQ ใช้ `postback` เพราะ `flow.py` รองรับ `a=faq_menu` อยู่แล้ว และไม่ต้องให้ข้อความโผล่ในห้องแชท

## กับดักที่เจอ/กันไว้แล้ว

- **`chatBarText` ยาวได้ไม่เกิน 14 ตัวอักษร** — ใช้ `เมนู IT` (7 ตัว) ถ้าใส่ยาวกว่านี้ LINE ปฏิเสธทั้ง request
- **รูป rich menu ต้องไม่เกิน 1 MB** และต้องเป็น 2500×1686 / 2500×843 / 1200×810 / 1200×405 เท่านั้น
  `setup_richmenu.py` เช็คขนาดไฟล์ให้ก่อนอัปโหลด จะได้ไม่ไปตายที่ API
- **อัปโหลดรูปใช้คนละโดเมน** (`api-data.line.me`) กับตอนสร้างเมนู (`api.line.me`) — ยิงผิดโดเมนจะได้ 404
- **สคริปต์ที่ print ภาษาไทยบนเครื่องนี้ต้อง `sys.stdout.reconfigure(encoding="utf-8")`** ไม่งั้นพังด้วย
  `UnicodeEncodeError: 'charmap' codec` เพราะ PowerShell ตั้ง stdout ของโปรเซสลูกเป็น cp1252
  (ทั้งสองสคริปต์ในโฟลเดอร์นี้ใส่ให้แล้ว)

## สร้างรูปใหม่เมื่อไหร่ก็ได้

```powershell
pip install pillow
python make_assets.py
python setup_richmenu.py      # อัปโหลดทับของเดิม
```

แก้ข้อความ/สี/ไอคอนของปุ่มได้ที่ตัวแปร `TILES` ใน `make_assets.py` (ไอคอนวาดด้วยโค้ดล้วน ไม่ได้ใช้ไฟล์ภาพ
ภายนอกและไม่ใช้ emoji font จึงได้ผลเหมือนกันทุกเครื่อง) — ถ้าเปลี่ยน**จำนวน**ปุ่ม ต้องแก้ `BUTTONS`
ใน `setup_richmenu.py` ให้เท่ากันด้วย ไม่งั้นพื้นที่กดจะเหลื่อมกับรูป
