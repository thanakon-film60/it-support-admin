## คู่มือแยกตามบทบาท — ฉบับ 1.1

ใช้สองชุดนี้เมื่อต้องการแจกเอกสารแยกกลุ่มผู้ใช้งาน ทั้งสองชุดมีหน้าปก โลโก้ สารบัญ เลขบท เลขภาพ และเลขหน้าของตนเอง

- **พนักงานผู้แจ้งเรื่อง — 16 หน้า:** [PDF](users/IT-Support-User-Guide-TH.pdf) · [Word](users/IT-Support-User-Guide-TH.docx) · [HTML](users/IT-Support-User-Guide-TH.html)
- **เจ้าหน้าที่ IT — 18 หน้า:** [PDF](it/IT-Support-IT-Staff-Guide-TH.pdf) · [Word](it/IT-Support-IT-Staff-Guide-TH.docx) · [HTML](it/IT-Support-IT-Staff-Guide-TH.html)

คู่มือพนักงานครอบคลุมการแจ้งเรื่องผ่าน LINE ติดตามสถานะ และยืนยันผล คู่มือ IT ครอบคลุมการรับงาน อัปเดตสถานะ และจัดการข้อมูลหลังบ้าน แต่ละชุดมีหัวข้อแก้ปัญหาและรายการตรวจสอบเฉพาะบทบาท

ตรวจจำนวนหน้า PDF ตรงกับสารบัญ ภาพโหลดครบ และไม่มีเนื้อหาล้ำท้ายกระดาษทั้งสองชุด ตรวจโครงสร้าง XML ของ Word ผ่าน ข้อจำกัดการตรวจการแบ่งหน้า Word ยังคงตามด้านล่าง

สร้างไฟล์ใหม่ด้วย `build_manual.py --audience users` และ `render_manual.py --audience users` สำหรับพนักงาน หรือเปลี่ยนเป็น `--audience it` สำหรับเจ้าหน้าที่ เนื้อหาที่ปรับตามบทบาทอยู่ใน `split_content.py` ผลตรวจแยกเก็บใน `users/validation.json` และ `it/validation.json`

ครอบคลุมการแจ้งงานผ่าน LINE การติดตามและยืนยันผล และเมนูหลังบ้านทั้ง 10 เมนู มีภาพประกอบ 17 ภาพ ใช้โลโก้เดิมจาก `line-oa/source/logo-source.png` ภาพ LINE มาจากโฟลเดอร์ที่มีอยู่จริงคือ `It-support_Pictures` และภาพเว็บจาก `Claude outputs`.

เนื้อหาตรวจเทียบกับโค้ดและเอกสารในโครงการ ณ วันที่จัดทำ โดยอธิบายความต่างของภาพรุ่นก่อนกับขั้นตอนปัจจุบัน ไม่ได้ส่งข้อความ LINE หรือเปลี่ยนข้อมูลระบบจริงระหว่างจัดทำ

## ผลตรวจ

- PDF 28 หน้า ตรงกับสารบัญ
- HTML โหลดภาพครบ และไม่มีเนื้อหาล้ำเข้าเชิงอรรถ / ท้ายกระดาษ
- ตรวจภาพตัวอย่างหน้าปก หน้ารูปประกอบ ตาราง และขั้นตอนอัปเดต Ticket
- ตรวจโครงสร้าง XML ของ DOCX ผ่าน แต่ไม่สามารถเปิด Microsoft Word ผ่าน COM ในเซสชันนี้ได้ (`80070520`) จึงยังไม่ได้ตรวจการแบ่งหน้าด้วย Word โดยตรง เลขหน้าในสารบัญอ้างอิง PDF; Word อาจแบ่งหน้าต่างกันตามฟอนต์และการตั้งค่าเครื่อง

## ไฟล์สำหรับปรับปรุงคู่มือ

- `build_manual.py` — เนื้อหาและตัวสร้าง HTML / DOCX
- `render_manual.py` — สร้าง PDF และตรวจการจัดหน้าด้วย Chromium / Playwright
- `manual-content.json` — สำเนาเนื้อหาแบบมีโครงสร้างที่สร้างจากสคริปต์
- `validation.json` — ผลตรวจจำนวนหน้าและขอบเขตเนื้อหา
- `preview-*.png` — ภาพตัวอย่างหน้าที่ใช้ตรวจรูปแบบ

เมื่อแก้เนื้อหาใน `build_manual.py` ให้รันสคริปต์นั้นก่อน แล้วรัน `render_manual.py` เพื่อสร้างผลลัพธ์ใหม่ ตรวจ `validation.json` และทบทวนสารบัญเมื่อมีการเพิ่ม / ลดหน้า
